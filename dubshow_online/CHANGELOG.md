# Changelog - DubShow Online 2.0

## 2.0.0

- Redesenho visual inspirado no mock enviado pelo usuário.
- Adicionado **modo singleplayer**.
- Fluxo inicial alterado para **Play Online** e **Singleplayer**.
- Interface simplificada para aceitar **somente link do YouTube**.
- Ajustada a criação de sala para permitir `max_players = 1`.
- Melhorada a sincronização do take com o diálogo de referência usando alinhamento automático por correlação.
- Revisada a mixagem da voz do jogador para reduzir o efeito de voz "muito alta".
- Atenuação da voz central do vídeo revisada para preservar melhor a trilha de fundo.
- README atualizado com recomendação de uso no Render em vez do Quick Tunnel.
