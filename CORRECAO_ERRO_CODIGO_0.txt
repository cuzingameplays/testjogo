CORRECAO DO ERRO "CODIGO 0"

O codigo 0 significa que o instalador anterior terminou sem erro, mas o script
nao encontrou o Python no caminho esperado. Esta versao usa Python portatil e
nao depende mais do instalador tradicional.

PARA UMA INSTALACAO NOVA:
1. Extraia todo o ZIP.
2. Abra ABRIR_SALA_ONLINE.bat.

SE VOCE JA TENTOU INSTALAR A VERSAO ANTERIOR:
1. Feche todas as janelas do DubShow.
2. Abra REPARAR_INSTALACAO.bat.
3. Depois abra ABRIR_SALA_ONLINE.bat.

Nao execute os arquivos diretamente dentro do ZIP.
